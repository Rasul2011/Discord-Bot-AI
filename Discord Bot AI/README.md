# 🤖 Discord AI Bot

## Description
A simple AI-powered Discord bot that responds to user prompts, stores users in a database, and supports different response styles.

## Features
- AI response generation
- SQLite database user tracking
- Different response styles (e.g. "kid", "teacher")
- Error handling and validation

## Commands
- `!chat <prompt>` – Get a standard AI response
- `!styled <style> <prompt>` – Get a styled response (e.g. `!styled kid What is gravity?`)
